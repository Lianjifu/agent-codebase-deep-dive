# Hermes 多模态设计

> ⚠️ 待源码公开后补充

## 预期内容

### 多模态输入处理

```
用户输入
  ├── 文本 ──────► LLM 理解
  ├── 图像 ──────► 视觉编码器
  ├── 音频 ──────► 语音识别 / 音频编码
  └── 视频 ──────► 帧提取 + 视觉编码
```

### 模态融合策略

| 策略 | 说明 |
|------|------|
| 早期融合 | 原始特征直接拼接 |
| 晚期融合 | 各模态独立处理后再合并 |
| 交叉注意力 | 各模态特征互相 Attend |

### 多模态输出

- 文本响应 + 工具调用
- 图像生成（结合用户图片）
- 语音合成（TTS）
