## 预期学习方向

### 1. 多模态设计

根据项目名 "Hermes"（希腊信使）推测，核心能力可能包括：
- **多模态输入**：文本、图像、音频、视频混合输入处理
- **多模态输出**：文本生成 + 工具调用 + 媒体生成
- **模态转换**：不同格式之间的转换能力

### 2. 工具系统

参考 Claude Code 的 40+ 工具设计，预期 Hermes 可能有：
- 自定义工具注册机制
- 工具权限和沙箱
- 工具组合和工作流

### 3. Agent 状态管理

- 长期记忆 vs 短期上下文
- 多会话状态隔离
- 背景任务处理
