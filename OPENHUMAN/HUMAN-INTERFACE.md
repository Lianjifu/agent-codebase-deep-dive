# OpenHuman Human 接口

> ⚠️ 待源码公开后补充

## 预期 Human-in-the-Loop 流程

```
Agent 识别需要人类介入
  ↓
暂停执行，发送审批请求
  ↓
人类接收通知（多渠道）
  ↓
人类审查并决策
  ├── 批准 → Agent 继续执行
  ├── 拒绝 → Agent 停止并记录
  └── 修改 → Agent 按修改执行
  ↓
记录决策到审计日志
```

### 介入触发条件

| 条件 | 说明 |
|------|------|
| 成本超限 | 单次操作成本超过阈值 |
| 敏感操作 | 删除/发送等高风险操作 |
| 不确定决策 | Agent 置信度低于阈值 |
| 主动请求 | Agent 主动请求人类指导 |

### 审批 UI

预期包含：
- Web 审批界面
- 飞书/微信通知
- 快速操作（批准/拒绝/修改）
